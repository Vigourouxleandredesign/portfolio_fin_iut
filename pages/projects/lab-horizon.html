Lab Horizon

La recherche calédonienne, enfin lisible. Un catalogue public de publications vulgarisées, un espace chercheur pour les relire, et toute la plateforme qui se relance en une commande.

Lire le récit Retour aux projets
En bref

En bref

  • Le problème

    Les travaux des chercheurs de Nouvelle-Calédonie sont publiés dans des canaux peu accessibles au grand public.

  • Ce que j’ai fait

    Développement front, UX/UI (maquettes, parcours utilisateur), architecture et documentation ; mise en place des outils anti-régression pour le développement assisté par IA et d’un processus de vérification sécurité avant la mise en production, inspiré de la CI/CD.

  • Le résultat

    Une plateforme livrée avec son dossier de passation : catalogue par domaine, fiche publication vulgarisée, espace chercheur et contrôles anti-régression.

Récit du projet

I

Rendre la science lisible

Chaque publication a sa fiche : un résumé vulgarisé, une grille « Quoi / Qui / Quand / Labo » et le lien vers le document source. Le visiteur explore par domaine — biologie, chimie, géosciences, histoire, informatique, mathématiques, physique… — sans créer de compte.

  • Biologie

  • Chimie

  • Géosciences

  • Histoire

  • Informatique

  • Mathématiques

  • Physique

II

Un produit, pas une maquette

Front React + TypeScript, API Laravel 12 avec authentification Sanctum, MySQL et Redis : tout tourne dans Docker derrière une seule adresse. Les publications peuvent être importées depuis HAL, l’archive ouverte nationale.

III

Penser à l’équipe suivante

Le projet est remis avec un dossier de passation (lancer, maintenir, faire évoluer). Avant chaque livraison, une commande npm run gate vérifie types, secrets, couleurs, tests et build : un garde-fou pensé comme une petite CI, qui empêche aussi le code produit avec une IA de faire régresser le projet.

IV

Ce qui reste à venir

L’assistant conversationnel (RAG) et la PWA sont cadrés pour une V2 : la V1 se concentre sur un catalogue fiable.
